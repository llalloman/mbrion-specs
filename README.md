# Mbrion Spec Driven Development

Repositorio genérico para organizar especificaciones de proyectos de Mbrion mediante Spec Driven Development.

## Estructura

- `templates/`: plantillas reutilizables para especificaciones.
- `projects/`: especificaciones organizadas por proyecto.
- `adr/`: registros de decisiones arquitectónicas.

Este repositorio contiene especificaciones y decisiones. No contiene código fuente de los proyectos.
